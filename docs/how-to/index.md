# How-to guides

Task-focused recipes for common reservoir-engineering workflows. Each
page shows the shortest working code, points at a runnable script in
``story_tests/`` to copy from, and assumes you've already loaded a
``WellDataManager``.

```{toctree}
:maxdepth: 1

fit-regressions-per-group
set-discrete-colors
pool-data-across-wells
export-petrel-equations
build-scal-deliverable
display-well-logs
```

If your workflow doesn't appear here, the
[user guide](../user-guide/loading-data.md) is the topical reference;
the [API docs](../api/index.md) cover every public class and method.
